Integritetspolicy

Prillan — privat verktyg för personligt bruk
Gäller från 12 november 2026

1. Ansvarig

Applikationen är ett privat verktyg som körs och ägs av en enskild person på egen hårdvara. Det finns ingen organisation, ingen extern användarkrets och ingen delning av konton. Kontakt: Filip.km.olsson@proton.me

2. Vilka data som behandlas

Endast data från det Google-konto som ägaren själv har auktoriserat, och endast de behörigheter som ägaren godkänner i Googles samtyckesdialog. Vilka behörigheter som är beviljade framgår när som helst av ägarens eget konto på myaccount.google.com/permissions.

3. Hur data används

Uteslutande för att tillhandahålla applikationens funktioner åt ägaren själv. Data används inte för annonsering, profilering eller vidareförsäljning, och används inte för att träna maskininlärningsmodeller.

4. Var data lagras

  • OAuth-token (access- och refresh-token) lagras i en lokal fil på ägarens egen server i hemnätverket, läsbar endast för ägarens användarkonto.
  • Behandlade data sparas som vanliga filer på samma maskiner.
  • Ingen data lagras hos tredje part. Inga externa analystjänster används.

5. Delning

Data delas inte med någon. Undantaget är det ägaren själv uttryckligen begär, till exempel att en sammanställning skickas till en mottagare som ägaren anger.

6. Lagringstid och radering

Token behålls tills ägaren återkallar åtkomsten. Åtkomst återkallas när som helst på myaccount.google.com/permissions, varefter refresh-tokenet slutar fungera omedelbart. Lokala filer raderas av ägaren på samma maskiner.

7. Säkerhet

Tokenfilen skyddas av filsystemets rättigheter, och maskinerna nås endast från hemnätverket eller via ägarens privata VPN. Inga portar exponeras mot internet för applikationens räkning.

8. Google API Services User Data Policy

Användningen av information som tas emot från Google API:er följer Google API Services User Data Policy, inklusive kraven om begränsad användning (Limited Use). Data läses endast för att tillhandahålla funktionerna ovan, överförs inte till tredje part, används inte för annonsering och läses inte av människor.

9. Ändringar

Vid ändringar uppdateras datumet högst upp på sidan.
